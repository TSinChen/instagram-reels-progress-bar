# Privacy Policy — Instagram Reels Progress Bar

_Last updated: 2026-08-10_

## The short version

This extension does not collect, store, transmit, or sell any personal data. There is no analytics, no telemetry, no tracking, and no server. Nothing ever leaves your browser.

## What the extension does

Instagram Reels Progress Bar draws a draggable seek bar over videos on `instagram.com` so you can jump to any point in a video. It reads the current playback position and duration of the video element on the page in order to draw the bar, and it writes a new playback position when you drag it. That is the entire interaction with the page.

## What is stored

The extension stores exactly four appearance preferences using Chrome's `storage.sync` API:

| Setting | Values |
|---|---|
| Bar thickness | a number between 2 and 8 |
| Handle size | a number between 8 and 20 |
| Hover area height | a number between 8 and 32 |
| Show time label | `true` or `false` |

These are stored by Chrome in your own browser profile and, if you have Chrome Sync enabled, synced across your own devices by Google. They are never sent to the developer or to any third party. Uninstalling the extension removes them.

## What is not collected

- No browsing history
- No page content, video content, captions, or usernames
- No account information or credentials
- No IP addresses, device identifiers, or location
- No analytics or usage statistics

## Permissions

| Permission | Why |
|---|---|
| `storage` | To remember the four appearance settings above. |
| Host access to `instagram.com` | The extension needs to run on Instagram pages to find the video element and draw the seek bar over it. It runs on no other website. |

## Network activity

The extension makes no network requests of its own. It bundles no remote code and loads nothing from external servers.

## Changes

If this policy ever changes, the updated version will be published at this same address and the date above will be updated.

# 隱私權政策 — Instagram Reels Progress Bar

_最後更新：2026-08-10_

## 一句話版本

這個擴充功能不蒐集、不儲存、不傳送、不販售任何個人資料。沒有分析工具、沒有遙測、沒有追蹤、沒有伺服器。所有東西都留在你的瀏覽器裡。

## 這個擴充功能做什麼

Instagram Reels Progress Bar 在 `instagram.com` 的影片上畫一條可拖曳的進度條，讓你跳到影片的任意位置。它會讀取頁面上影片元素的目前播放位置與總長度來畫這條進度條，並在你拖曳時寫入新的播放位置。與頁面的互動僅止於此。

## 儲存了什麼

擴充功能使用 Chrome 的 `storage.sync` 儲存四項外觀設定：

| 設定 | 可能的值 |
|---|---|
| 進度條粗細 | 2 到 8 之間的數字 |
| 拖曳圓點大小 | 8 到 20 之間的數字 |
| 感應區高度 | 8 到 32 之間的數字 |
| 顯示時間標籤 | `true` 或 `false` |

這些資料由 Chrome 存在你自己的瀏覽器設定檔中；若你開啟了 Chrome 同步功能，Google 會在你自己的裝置之間同步它們。這些資料不會傳送給開發者或任何第三方。移除擴充功能即會一併移除。

## 沒有蒐集什麼

- 不蒐集瀏覽紀錄
- 不蒐集頁面內容、影片內容、貼文文字或使用者名稱
- 不蒐集帳號資訊或憑證
- 不蒐集 IP 位址、裝置識別碼或位置資訊
- 不蒐集任何分析或使用統計

## 權限說明

| 權限 | 用途 |
|---|---|
| `storage` | 記住上述四項外觀設定。 |
| `instagram.com` 的網站存取權 | 擴充功能需要在 Instagram 頁面上執行，才能找到影片元素並把進度條畫上去。它不會在其他任何網站執行。 |

## 網路行為

擴充功能不會發出任何自己的網路請求，不含遠端程式碼，也不從外部伺服器載入任何東西。

若本政策有所變更，更新後的版本會發布在同一個網址，並更新上方的日期。
